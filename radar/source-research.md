## UXUX11 可直接觀察的內容

- LINE 名錄頁面標示全部 77 筆，按縣市篩選，顯示店名與 LINE ID。點擊好友按鈕會進入 LINE 的 `line.me/ti/p/` 好友入口。
- 同頁下半部另有獨立抽選資料：批次名稱、最後更新時間、手動／連續操作模式、產品篩選、時間篩選、各門市產品與活動時段，以及「本週未販售」門市清單。
- 本次檢查時，頁面仍顯示最後更新 2026-11-06 16:17，批次日期為 2026-11-06 至 2026-11-07；截至 2026-11-08 該批次已過期。
- 部分活動時段標示為「依門市營業時間推估」，因此活動時間欄位不一定全部直接來自官方公告。
- Cofacts 對該頁面的歷史摘要指出，它只顯示有抽選文章的門市，並保留抽選開始時間、陀螺品名與抽獎網址。這是對公開頁面內容的第三方摘要，不是作者技術文件。

- 可依縣市、店家、商品篩選；產品名稱中包含型號、中文名稱及部分配置資料。
- 搜尋索引顯示一份歷史快照：750 項、78 家店、40 種商品，最後更新 2026-10-08 12:14:02。頁面提醒 62 家仍屬前一批，連結雖可開啟但已不能抽選。
- 因此它適合當產品名稱／型號及歷史店家活動索引，不應把舊批次視為目前可參加。

## 對方如何取得資料？

公開頁面未揭露足以核實的原始碼、API、資料匯入程式或編輯流程。無法斷言是自動爬蟲、Facebook API、LINE API 或人工維護。

可合理推測的資料工作流程是：

1. 先建立各門市 LINE 官方帳號名錄，LINE 好友連結可直接由帳號 ID 組成，無需讀取 LINE 訊息。
2. 從各門市公開公告／活動貼文整理出門市、商品、抽選開始與截止時間、抽選網址。
3. 進行人工或半自動核對，尤其對公告未明示的時間加註推估。
4. 將每一批活動獨立整理，並把上一批轉為歷史或已結束。

以上第 1 點可由頁面按鈕和 LINE ID 驗證；第 2–4 點是依欄位、批次時間與推估註記推論，並非作者已公開證實的實作方式。

## 本專案的合併原則

- Google Sheet 的 68 筆門市是使用者指定的主要聯絡資料來源，不覆蓋其中的 LINE ID、Facebook URL。
- UXUX11 LINE 名錄補充 10 個不同地點，其中 9 個是額外 LINE ID，台東家樂福與台東秀泰共用 `@438glrqv`。補充資料獨立存放於 `radar/data/stores-supplemental.json`，每次 Google Sheet 同步時都會重新合併，不會被覆蓋。
- UXUX11 抽選批次與 BeyBuilder 歷史目錄做為活動探索來源，不把未過濾的舊紀錄匯入目前有效活動。
- 目前 `draw-events.json` 仍保持空白，因公開頁面抽選按鈕的實際目標網址與每筆活動完整結構無法由文字擷取確認；因此本站顯示兩個外部來源入口，且不假造即時抽選資料。
- 以後要做自動匯入，應在確認可穩定存取的公開資料端點／HTML 結構後，另做來源專用解析器，保留 `sourceUrl`、`fetchedAt`、`announcedAt`、`startsAt`、`endsAt`、`timeInferred`、`status`，並以活動截止時間判斷過期。
