# BEYBLADE X Radar v0.4.5

本網站是獨立實作的 Funbox 預購／抽選整理工具。參考網站只用來研究操作模式，不嵌入、不連結，也不把它們當成本站的抽選頁。

- 活動批次下拉選單：選擇最近一次或歷史批次。
- 商品下拉選單：依批次動態產生，並保留各批次最後選擇的商品。
- 活動卡片點擊後顯示本站自己的活動詳情。
- 只有取得該筆活動的官方抽選網址才啟用抽選入口。
- 手動／連續處理模式；返回後由使用者確認是否完成。
- 台中預設，可切換其他縣市。
- LINE 好友名單收在次要區塊。
- 誠品商品獨立分頁。

目前唯一有完整可核對的最近批次快照為 2026/11/06–11/07 BX-53，已結束；本站列出其中台中 9 家活動明細。尚未取得單筆官方抽選網址，所以不顯示可抽按鈕。
