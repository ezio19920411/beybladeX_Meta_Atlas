# V0.4.3

- 把 UXUX11 原站「抽選模式」設為主要抽選入口；卡片、主按鈕、內嵌 iframe 及全螢幕備援使用同一個來源網址。
- 明確區分抽選入口與 LINE 好友入口，LINE 名單維持折疊次要區。
- 批次卡片顯示最後核對的商品型號／名稱、日期、來源更新時間與門市數。
- 原站內嵌即時抽選清單；原站手動／自動連抽功能由來源網站負責。內嵌失敗時可全螢幕開啟。
- 商品拉霸由抽選事件、誠品追蹤商品、最近批次商品動態建立候選池並去重。
- 拉霸最後一次選中的商品與時間保存在本機瀏覽器，重整後保留，且納入個人紀錄備份。
- 明確標示拉霸為隨機挑商品，不代表官方抽選或中籤結果。
- 更新 Service Worker 快取名稱與靜態資源版本，避免舊版 PWA 快取遮蔽新介面。
